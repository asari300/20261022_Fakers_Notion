データベースとテーブルのビュー

列（テキスト・数値・チェック）と行とセルが 2 タブで同期する

データベースはページの中のブロック。同期と保存は今の仕組みのまま
目的

このセッションでやること

  • P3 の 2 回目。features.md の方針「ビューはページの中のブロック、データは Y.Map の行」を形にする
  • テーブルのビューで、列の追加・名前・型・削除、行の追加・削除、セルの編集
  • ボード・リスト・フィルタ・フォーミュラの列は次から
決定と理由

決めたこと（ADR-0008）

項目決定理由
置き場所type: "database" のブロック同期・保存・Presence がそのまま使える
列と行ブロックの columns と rows（Y.Array の Y.Map）列や行を足す・消すが同時でも収束する
セル文字列・数値・真偽値をそのまま。後勝ち小さく始める。同じセルの同時入力は片方が消える（shortcut）
型を変えたとき値は消さず、合わない値は空として表示型を戻せば戻る。壊れた値で表全体が読めなくならない
サーバ表を読まないRust と Elixir は種類と題名だけ。表はクライアントの FFI が読む
