決定と理由

決めたこと

項目決定理由
相互運用ゲートyrs → yjs に加えて yjs → yrs も（絵文字つき）。cargo を node から呼ぶ 1 本のスクリプト両方向が通らないと縦スライスは動かない。UI の前に確かめる
SPA の実装Opus（effort medium）のサブエージェントに契約（JSON・Channel・FFI の API）を渡して任せたElixir 側と並行できる。契約が固定されていた
Enter と IMEevent.advanced("keydown") で isComposing を見る日本語の変換確定の Enter でブロックを作らない
差分計算FFI の diff_text（UTF-16、サロゲートペアを切らない）yjs の位置は UTF-16。Gleam の文字列長は書記素
E2EPlaywright の Python（src/Python/e2e）で自動化し mise run test に入れた完了条件そのもの。手動確認を残さない
static_pathsfonts と images を外すディレクトリが無く、dev で Plug.Static が落ちる
既知の制限ブロックは controlled input。リモート編集でキャレットが末尾に飛ぶP2 で contenteditable にする
